# CURA STORE — Premium Dental Supplies

متجر أسنان متكامل بخطوات (Contra Angle → Anesthesia → Essentials → بيانات التوصيل) بيزوّد فاتورة PDF عربية بخط **Noto Sans Arabic** ويبعتها على واتساب لمسؤول التأكيد.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع كامل (واجهة + منطق + مولّد الفاتورة) — standalone |
| `bg-fx.js` | خلفية جزيئات 3D بـ Parallax (بدون مكتبات) |
| `logo.jpg` | لوجو المتجر (مطلوب جنب الملفات) |
| `--0XX.jpg` / صور المنتجات | صور الأصناف بنفس أسمائها في `PD` و`ER` |
| `7878.jpeg` | صورة Dental Anesthetic 10 Cartridges (Blue) |

## المميزات

- 21 خطوة اختيار + أدوات أساسية قابلة للتعديل والحذف والبحث
- نظام **Cura Points**: نقاط + مستويات + 5 إنجازات محفوظة في `localStorage`
- أصوات Web Audio (إضافة/حذف/نجاح) + كونفيتي عند إتمام الطلب
- 3D Tilt لكروت المنتجات + خلفية جزيئات تفاعلية
- فاتورة PDF عربية بالكامل (Noto Sans Arabic ← Amiri ← Cairo fallback) في صفحة A4 واحدة مع ضغط تلقائي للصفوف
- Dark mode + حفظ تلقائي لكل حاجة + زر طلب جديد

## التشغيل / النشر

شغّل `index.html` مباشرة، أو ارفع كل الملفات (الكود + الصور) في نفس الفولدر على GitHub Pages — مفيش build ولا خطوات إضافية.

> ملحوظة: تحميل خط الـ PDF بيحتاج نت أول مرة (من fonts.gstatic.com)، ولو النت مقطوع بيرجع للخط الافتراضي تلقائيًا.
